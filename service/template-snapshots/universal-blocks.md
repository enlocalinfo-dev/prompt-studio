# Genspark 全案件必須ブロック（コピペ用）

新規 `genspark_prompt.md` の **`text` ブロック**に、毎回以下3セクションを入れる。  
詳細・クォータ表は `.cursor/rules/genspark-information-density-1p5.mdc` 等を参照。

---

## 1. 情報密度1.5倍（`text` 内に貼る）

```text
━━━━━━━━━━━━━━━━━━━━━━━━━
【情報密度1.5倍ロック（数値必達）】
━━━━━━━━━━━━━━━━━━━━━━━━━
- 「1.5倍」は**下記最低行数を満たす**ことで達成する（抽象指示のみは不可）。
- **簡略化・「要点のみ」・カード1行化・フロー短ラベルのみは禁止**。
- **全内容スライド**：リード＋サブリード ＋ 本体 ＋ **補足1行**（可視テキスト**合計6行以上**）。
- **3カード**（各）：見出し1 ＋ 本文**3行** ＋ 補足**1行**。
- **4ボックス**（各）：見出し1 ＋ 本文**2行**。
- **5段階フロー**（各段）：ラベル ＋ **説明1行**。
- **2カラム比較**（各列）：箇条**4〜5項目**。
- **KPIカード**（各）：数値＋ラベル＋**前提・根拠1行**。
- はみ出し時：**箇条削除より先に**段組み・セル2行・図内ラベルで調整。
```

## 2. 絵文字禁止（`text` 内に貼る）

```text
━━━━━━━━━━━━━━━━━━━━━━━━━
【非AI感・装飾ロック（必須）】
━━━━━━━━━━━━━━━━━━━━━━━━━
- **絵文字・スタンプ・ステッカー風記号は一切使用しない**。
- アイコンは**0〜2個/スライド**、**単色線画**のみ。絵文字で代用しない。
- 4ボックス・カードの装飾も同様。
```

## 3. ビジネストーン（B2B提案・`text` 内に貼る）

```text
- トーン：**ビジネスライク**。経営層向けは負荷軽減・ROI・内製化を前面に。
- **禁止表現**：直撃／解放（単独）／止める／口語の煽り表現。
- **禁止出力**：Unicode絵文字全般／スタンプ風記号。
```
